# Estimating the carbon impacts of leakage from forest restoration and the costs of reducing them

This repository contains the code and input data required to reproduce the analyses presented in:

d'Albertas et al. Estimating the carbon impacts of leakage from forest restoration and the costs of reducing them.

The analysis evaluates the carbon and cost implications of leakage from tropical forest restoration projects in Brazil and explores strategies to reduce and mitigate leakage through spatial prioritization and targeted intensification.

## Repository structure

The repository is structured as follows:

- [`scripts/`](https://github.com/franciscodalbertas/Estimating-the-carbon-impacts-of-leakage-from-forest-restoration-and-the-costs-of-reducing-them/tree/main/scripts):Scripts used to run the analyses
- [`scripts/figures/`](https://github.com/franciscodalbertas/Estimating-the-carbon-impacts-of-leakage-from-forest-restoration-and-the-costs-of-reducing-them/tree/main/scripts/figures):Scripts used to reproduce manuscript main figures
- [`functions`](https://github.com/franciscodalbertas/Estimating-the-carbon-impacts-of-leakage-from-forest-restoration-and-the-costs-of-reducing-them/tree/main/functions): Custom functions that perform the necessary calculations
- [`variables/`](https://github.com/franciscodalbertas/Estimating-the-carbon-impacts-of-leakage-from-forest-restoration-and-the-costs-of-reducing-them/tree/main/variables):Folder for input raster datasets
- [`mitigation_inputs/`](https://github.com/franciscodalbertas/Estimating-the-carbon-impacts-of-leakage-from-forest-restoration-and-the-costs-of-reducing-them/tree/main/mitigation_inputs):Input tables with project features to run the mitigation analysis
- [`results_with_mitigation/`](https://github.com/franciscodalbertas/Estimating-the-carbon-impacts-of-leakage-from-forest-restoration-and-the-costs-of-reducing-them/tree/main/results_with_mitigation): Result of the mitigation analysis
- [`output_tables/`](https://github.com/franciscodalbertas/Estimating-the-carbon-impacts-of-leakage-from-forest-restoration-and-the-costs-of-reducing-them/tree/main/output_tables): Final tables generated by the analysis, aggregating the intermediate results

## Data availability

Input raster datasets required to reproduce the analyses are available from the repository release page:

https://github.com/franciscodalbertas/Estimating-the-carbon-impacts-of-leakage-from-forest-restoration-and-the-costs-of-reducing-them/releases

After downloading, unzip and place all raster files inside the variables/ folder before running the scripts.

## Reproducing the analysis

Scripts required to generate the results are located in the scripts/ directory.

These scripts are numbered and ordered sequentially, and should be run in that order to reproduce the output tables used in the manuscript.

## Scripts

The `scripts/` directory contains the full pipeline used to generate the results presented in the manuscript. Scripts are numbered and should be run sequentially.

Below is a description of each script:


- `01_a_run_project_features_selection_sample_local.R`: generate input data for projects for local domain analysis;
- `01_b_run_project_features_selection_sample_biome.R`: generate input data for projects for biome domain analysis;
- `01_c_run_project_features_selection_sample_country.R`: generate input data for projects for country domain analysis;
- `02_run_SCC_project_features_selection_sample.R`: for the previous generated input data, apply the SCC discounting;
- `03_a_run_mitigation_costs_selection_sample_local_scale.R`: run mitigation analysis for local domain;
- `03_b_run_mitigation_costs_selection_sample_biome_scale.R`: run mitigation analysis for biome domain;
- `03_c_run_mitigation_costs_selection_sample_country_scale.R`: run mitigation analysis for country domain;
- `04_a_generating_final_table_low_high_leakage.R`: aggregate results for all domains into a single table, for low- and high-leakage projects;
- `04_b_generating_final_table_random_projects.R`: aggregate results for all domains into a single table, for the projects sampled across the full distribution;
- `05_adjusting_currency_inflation.R`: adjust final costs converting from BRL to USD;
- `figures/results`: scripts to generate the figures on the main manuscript;
