# Estimating the carbon impacts of leakage from forest restoration and the costs of reducing them

**Code to reproduce the analyses for the paper**

To reproduce the analysis, the first step is to download the input raster files from the release page:
https://github.com/franciscodalbertas/Estimating-the-carbon-impacts-of-leakage-from-forest-restoration-and-the-costs-of-reducing-them/releases

The files must be saved into the **variables** folder.

Inside the **scripts folder**, the scripts required to generate the output tables with results are ordered sequentially.

Inside this same folder, the **figures** folder contains the scripts to generate the main figures from the manuscript.
